# Gated study protocol — no confirmatory campaign launched

## Admission gates

1. Physical object-relative identity and atomic geometry ownership tests pass.
2. Candidate pool, controller, geometry/safety limits, authority setting and
   terminal interface match. Same initial observation produces the same pool.
3. Independent giver replay, no premature closure, no second commitment,
   no postcommit search, source prediction/truth separation pass, including failures.
4. Snapshot-versus-result-use discrepancy and preview-versus-QP errors are bounded
   adequately for the tested interpretation. Snapshot proposals are NOT certificates.
5. Same-state terminal compatibility discrepancies have a reproducible mechanism.

Gate 4 has NOT passed. Do not use smoke outcomes as H1 or H2 evidence.

## H1

Treatment = supervisory reference-generation policy (current relative target with
observed-motion feedforward; short fixed-lookahead target; sampled future encounter
search and patch). A future pose necessarily changes when feasibility is evaluated;
this is part of the policy treatment, not a claim that only one scalar changed.
Use identical explicit outcome-blind candidate pools and diagnostic-only authority.
Do not provide the predictive winner or future-event shortlist to the reactive arm.
The acquisition interface requires stopping in every arm.

Primary Y = completion from trial start, including no-plan/no-commit failures.
Record measured relative velocity, pose error, tracking error, time-to-approach,
commitment and completion, abortions, grasp changes, latency, clearance and stage.
Predeclare practical superiority as +0.10 absolute completion probability. This
is a proposed practical bar (one extra completion per ten offers), not estimated
from the smoke runs. Require a simultaneous lower confidence bound above this
bar against BOTH competent simpler arms before arguing search earns complexity.
Use Holm adjustment for the two planned contrasts; paired cluster bootstrap
intervals over independent scenario realizations, and a prespecified logistic
mixed model for regime interactions as secondary analysis. Equivalence requires
a 90% paired interval within [-0.10,+0.10]; a nonsignificant result is not equivalence.

The four existing scenarios are regression cases only. Pilot new independent
realizations with initial position perturbations within +/-15 mm, orientation
perturbations within +/-5 deg, speed strata 0 (static), .04, .08, .12 m/s,
stop-profile durations .4, .85, 1.2 s and stop timing around the existing script.
Add small rotation only after verifying script, perception and geometry support.
Freeze a physically admissible envelope BEFORE confirmation; retain exclusions
with physical reasons. Sample easy and hard regimes, not only successful demos.

Randomize method order within paired realizations; use fixed recorded seeds and
identical pre-attachment giver scripts. Timing jitter is not an independent trial.
Pilot data estimate discordant-pair variance, compute-load variability and dropout,
not the desired winner. Exclude pilot seeds from confirmation. Choose N by paired
power simulation for the above practical-superiority criterion (80% or higher
power at a predeclared alternative), accounting for clustering and two contrasts.
No N=3 inference. If the available budget cannot support that N, report exploratory
characterization rather than confirmatory superiority.

## H2

First predict consequential error/failure, never intervene using kappa. Compute
kappa and generic metrics on identical sampled configurations, Jacobian frame,
row scaling and temporal window. Compare phase minima separately before a common
minimum across phases. Include joint-limit/velocity-weighted alternatives; record
requested twist magnitude/direction, available time, initial error, clearance and
prediction error as confounders. The conservative box is not actual QP bounds.

Split by whole independent trajectory/geometry realization, never sample rows.
Fit the same modest predictor with generic metrics, then add kappa/residual;
evaluate held-out calibration, log loss and discrimination with trial-level
intervals. A rank difference alone is insufficient. Define a consequential error
using existing capture/clearance/timeout limits, not a post-hoc threshold chosen
to favor kappa. Contact/transfer outcomes are simulation-model outcomes here.
Only reproducible added predictive value with a physical failure mechanism can
open an intervention-policy gate; only a failure not solved by competent existing
selection/reference tracking can open a new-controller gate.

## Predeclared project decisions

- Practical equivalence: simplify; no new method claim.
- Benefit of lookahead but not encounter search: simplify to lookahead.
- Search advantage alone: system validation unless a distinct mechanism survives
  primary-literature comparison.
- Kappa adds no held-out value: drop it from the proposed method.
- Different previews disagree at geometric tolerance boundaries: repair contracts;
  this does not establish nullspace or interaction-control novelty.
- No adequate preview/runtime correspondence: no certificate claim and no H2
  causal interpretation; stop confirmatory experiments until resolved.
